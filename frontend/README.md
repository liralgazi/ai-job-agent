# 🚀 AI Job Agent

A modern AI-powered job search platform built with React, Vite, and future-ready backend architecture for intelligent job discovery and automation.

The platform allows users to search and filter tech jobs based on role, location, technologies, experience level, and work preferences through a clean modern interface.

---

# ✨ Features

- Smart job search interface
- Advanced filtering system
- Modern dark-mode SaaS UI
- Built with React + Vite
- Dynamic job cards
- Search using Enter key
- Architecture ready for AI integration
- Focused on Israeli tech jobs

# 🏗️ Current Functionality

Users can:
- Filter jobs by role
- Filter by location
- Filter by work mode (Remote / Hybrid / On-site)
- Filter by experience level
- Filter by technologies

The UI currently uses mock job data while the backend architecture is being prepared for real-time job integrations.

# ⚙️ Setup Instructions

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/liralgazi/ai-job-agent.git
cd ai-job-agent
```

---

## 2️⃣ Install Dependencies

```bash
cd frontend
npm install
```

---

## 3️⃣ Run the Application

```bash
npm run dev
```

The app will run on:

```bash
http://localhost:5173
```
